Ontario High School One-Stop Learning Hub

Static Vercel-ready website.

Main sections:
- Grade 9–12 study pages
- Mathematics: foundations through calculus and vectors
- Science: biology, chemistry, physics, Earth/space/environment
- English, literacy, research, and OSSLT preparation
- Canadian/world history, geography, civics, law, and Indigenous histories
- Economics, business, accounting, entrepreneurship, and personal finance
- Technology, computer science, engineering design, cybersecurity, and skilled trades
- Careers, co-op, SHSM, apprenticeship, university, college, and workplace pathways
- Health, physical education, arts, French/languages
- Study skills, reference library, and browser-saved graduation checklist

Deployment:
1. Extract ZIP.
2. Upload contents to a GitHub repository.
3. Import into Vercel.
4. Use Static/Other framework preset.
5. No build command is required.

This site is a learning companion and does not replace official Ontario curriculum documents, school guidance, or official graduation audits.
