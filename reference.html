Student Reference Library

Common units, command words, conventions, and mistakes across high-school subjects.

Command words

  • Identify: name it
  • Describe: give characteristics
  • Explain: show how or why
  • Compare: similarities and differences
  • Analyze: break apart and connect evidence
  • Evaluate: judge using criteria and evidence

SI units

  • Length: metre (m)
  • Mass: kilogram (kg)
  • Time: second (s)
  • Temperature: kelvin (K) or °C as specified
  • Force: newton (N)
  • Energy: joule (J)
  • Power: watt (W)

Graph checklist

  • Descriptive title
  • Independent variable on x-axis
  • Dependent variable on y-axis
  • Labels and units
  • Appropriate scale
  • Best-fit line/curve when required

Common math errors

  • Dropping negative signs
  • Ignoring restrictions
  • Using degrees/radians incorrectly
  • Rounding too early
  • Forgetting units
  • Assuming correlation proves causation

Source citation

Record author, title, publisher/site, publication date, URL or database, and access information as required. Follow the style assigned by your teacher.

Lab report structure

  • Question/purpose
  • Hypothesis if required
  • Variables and materials
  • Procedure
  • Observations/data
  • Analysis
  • Conclusion and limitations
