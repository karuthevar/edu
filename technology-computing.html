Computing concepts

Build strong foundations before focusing on a programming language.

Computer science

Algorithm

Definition: A finite ordered set of steps for solving a problem.

Good algorithms are correct, clear, testable, and appropriately efficient.

Example: Binary search repeatedly halves a sorted search range.
Common mistake: Coding before defining inputs and steps.
Programming

Variable and data type

Definition: A named storage location whose value has a type.

Types such as number, string, and Boolean determine valid operations.

Example: age = 15 is numeric; name = 'Ava' is text.
Common mistake: Treating text '10' and number 10 as always identical.
Programming

Selection and iteration

Definition: Selection chooses among paths; iteration repeats instructions.

Conditions must be testable and loops need a correct stopping condition.

Example: If score ≥ 70, show passed; otherwise show review.
Common mistake: Creating an infinite loop.
Programming

Function

Definition: A reusable block of code for a specific task, often with inputs and an output.

Functions improve decomposition, testing, reuse, and readability.

Example: areaCircle(r) returns πr².
Common mistake: Making one function handle unrelated responsibilities.
Programming

Testing and debugging

Definition: Testing checks behaviour; debugging finds and fixes the cause of failure.

Use normal, boundary, invalid, and edge cases.

Example: Test a grade calculator with 0, 49.9, 50, 100, and invalid text.
Common mistake: Changing random code without reproducing the issue.
Digital literacy

Cybersecurity fundamentals

Definition: Practices protecting systems, accounts, and data.

Use unique passwords, MFA, updates, backups, least privilege, and phishing awareness.

Example: Open the official app instead of an unexpected login link.
Common mistake: Trusting a familiar logo as proof.
Technology

Engineering design process

Definition: Define, research, ideate, prototype, test, improve, and communicate.

Use criteria, constraints, measurement, safety, sustainability, and user needs.

Example: Test a bridge model, analyze failure, redesign, and retest.
Common mistake: Treating the first workable idea as final.
Technology

Accessibility by design

Definition: Designing so people with diverse abilities can use a product or environment.

Consider keyboard navigation, captions, contrast, structure, labels, and alternatives.

Example: A form uses labels and clear errors, not colour alone.
Common mistake: Adding accessibility only after completion.
