Grade 9: Mathematics

Algebra, relations, geometry, data, and financial literacy.

Scientific notation

Writing a number as a×10ⁿ with 1≤

Example: a|<10.|3.2×10⁵=320000.

Polynomial

Expression made of terms with non-negative integer exponents.

Example: 3x²−2x+5.

Like terms

Terms with identical variable factors.

Example: 3x and −5x are like terms.

Linear relation

Relation with constant first differences.

Example: Its graph is a straight line.

Rate of change

Change in output divided by change in input.

Example: For a line it is slope.

Slope

Vertical change divided by horizontal change.

Example: m=(y₂−y₁)/(x₂−x₁).

Y-intercept

Value where a graph crosses the y-axis.

Example: In y=mx+b it is b.

Function

Relation assigning one output to each input.

Example: Shown by tables, graphs, or equations.

Domain

Set of allowable input values.

Example: Often represented by x-values.

Range

Set of resulting output values.

Example: Often represented by y-values.

Scatter plot

Graph of paired numerical data.

Example: Can reveal correlation.

Correlation

Degree to which variables vary together.

Example: Does not prove causation.

Simple interest

Interest calculated on original principal only.

Example: I=Prt.

Compound interest

Interest calculated on principal plus accumulated interest.

Example: Growth accelerates over time.

Grade 10: Mathematics

Quadratics, analytic geometry, trigonometry, and finance.

Quadratic relation

Degree-two relation with a parabolic graph.

Example: y=x² is quadratic.

Parabola

Graph of a quadratic relation.

Example: Can open up or down.

Vertex

Maximum or minimum point of a parabola.

Example: In vertex form it is (h,k).

Axis of symmetry

Line dividing a parabola into mirror halves.

Example: x=h.

Zero

Input value where a function equals zero.

Example: Also called root or x-intercept.

Factoring

Rewriting an expression as a product.

Example: x²−9=(x−3)(x+3).

Sine ratio

Opposite divided by hypotenuse.

Example: sinθ=opp/hyp.

Cosine ratio

Adjacent divided by hypotenuse.

Example: cosθ=adj/hyp.

Tangent ratio

Opposite divided by adjacent.

Example: tanθ=opp/adj.

Midpoint

Point halfway between two coordinates.

Example: Average x and y separately.

Distance formula

Distance between coordinate points.

Example: Derived from Pythagorean theorem.

Compound interest

Interest on principal plus previous interest.

Example: A=P(1+i)ⁿ.

Present value

Current worth of a future amount.

Example: Used in loans and investments.
📐

Grade 11: Functions

Functions, transformations, exponentials, and trigonometry.

Function notation

Notation such as f(x) for output at input x.

Example: f(2) means evaluate at 2.

Inverse function

Function reversing another function.

Example: Requires a one-to-one restriction.

Transformation

Change in graph position, scale, or orientation.

Example: y=af(k(x−d))+c.

Exponential function

Function with a variable exponent.

Example: Models constant-percent growth.

Logarithm

Exponent needed to produce a number from a base.

Example: Inverse of exponential.

Radian

Angle measure based on arc length over radius.

Example: 2π radians=360°.

Sinusoidal function

Periodic function modeled with sine or cosine.

Example: Used for cycles.

Trigonometric identity

Equation true throughout its domain.

Example: sin²x+cos²x=1.

Arithmetic sequence

Sequence with constant difference.

Example: A linear pattern.

Geometric sequence

Sequence with constant ratio.

Example: An exponential pattern.

Average rate of change

Secant slope over an interval.

Example: [f(b)−f(a)]/(b−a).

Instantaneous rate of change

Tangent slope at a point.

Example: A preview of calculus.
📐

Grade 12: Advanced Mathematics

Advanced functions, limits, derivatives, and vectors.

Limit

Value a function approaches near a point.

Example: Foundation of derivatives.

Continuity

Property of having no break at a point or interval.

Example: Requires matching value and limit.

Derivative

Instantaneous rate of change or tangent slope.

Example: Written f′(x).

Differentiability

Existence of a derivative at a point.

Example: Implies continuity there.

Critical number

Domain value where derivative is zero or undefined.

Example: Used to find extrema.

Optimization

Finding maximum or minimum values under constraints.

Example: Uses derivatives.

Vector

Quantity with magnitude and direction.

Example: Represented by components.

Magnitude

Length of a vector.

Example: ||v||=√(v₁²+v₂²+v₃²).

Dot product

Scalar measuring directional alignment.

Example: a·b=||a||||b||cosθ.

Parametric equation

Coordinates expressed using a parameter.

Example: Models lines and motion.

Rational function

Ratio of polynomial functions.

Example: Denominator cannot be zero.

Logarithmic function

Inverse of exponential function.

Example: Solves exponential equations.

Antiderivative

Function whose derivative is given.

Example: Preview of integral calculus.

Meaning: Evolutionary baseline.
