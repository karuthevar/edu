Ontario Student Hub — Complete Consolidated 2026 Release

Includes:
- Existing detailed Grade 9–12 STEM definitions, laws, formulas, examples, and quizzes
- Expanded English, history, geography, civics, economics, business, financial literacy, technology, computing, and trades content
- Formula and theorem centre
- Cross-subject glossary
- Global search
- Bookmarks and reading progress
- Course planner and graduation planner
- Supabase sign-up/sign-in, profiles, forum, reporting, and moderation

Deployment:
1. Extract the ZIP so index.html is at the project root.
2. Upload all files to GitHub and import into Vercel.
3. No build command is required.
4. For accounts/forum, run supabase-schema.sql and configure supabase-config.js.
5. Never expose a Supabase service-role key.

This site is a study and planning companion, not an official Ministry publication, transcript, or graduation audit.
